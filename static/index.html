Official OpenAI Python SDK Integration

This server is a 100% drop-in replacement for OpenAI TTS and Whisper endpoints. Set base_url="http://localhost:8000/v1".

1. Text-to-Speech (TTS)

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed"  # Local API does not require key
)

# Synthesize speech
response = client.audio.speech.create(
    model="indic-speak-mlx",     # or "indic-speak", "tts-1"
    voice="Sravani",             # 44 Indic voices or alloy, echo, nova, etc.
    input="కరాగ్రే వసతే లక్ష్మీః కరమధ్యే సరస్వతీ",
    response_format="mp3"        # mp3, wav, flac, pcm
)

# Save to file
response.stream_to_file("output.mp3")

2. Automatic Speech Recognition (ASR / Whisper)

# Transcribe audio file
with open("output.mp3", "rb") as audio_file:
    transcription = client.audio.transcriptions.create(
        model="indic-transcribe",  # or "whisper-1"
        file=audio_file,
        language="te"              # or None for auto-detect
    )

print("Transcription:", transcription.text)

3. Streaming Audio Playback via cURL

# Stream direct audio chunks:
curl -X POST http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model": "indic-speak-mlx", "input": "నమస్కారం, ఇది ప్రత్యక్ష ప్రసారం", "voice": "Sravani", "stream": true, "response_format": "wav"}' \
  | ffplay -nodisp -autoexit -i -
